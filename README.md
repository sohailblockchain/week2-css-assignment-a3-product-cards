# Week 2 — CSS Assignment A3: Responsive Product Cards

This assignment focuses on building a responsive product page using **Flexbox, CSS Grid, and media queries**.

## 🎯 Objectives
Students will practice:
- Flexbox for navigation layout
- CSS Grid for product cards
- Responsive design with media queries
- Using rem units for spacing and text

## 📁 Files
- `index.html` — Starter HTML with comments
- `style.css` — Starter CSS with TODO tasks
- `assets/images/` — Demo product images


## ▶ How to Run
Open `index.html` in your browser.

See **ASSIGNMENT.md** for full instructions.

## ✅ Submission

- HTML

- Images

All layouts must be responsive on mobile and desktop.
