# Week 2 (CSS) — Assignment A3: Responsive Product Cards + Navigation

## Goal
Build a **responsive mini product page** using **Flexbox + Grid + media queries**.

You will create:
- A responsive top navigation (Flexbox)
- A responsive product cards section (Grid)
- A simple “Subscribe” form section (Flexbox/Grid)

---

## ✅ Requirements (Must Do)

### 1) Navigation (Flexbox)
- Logo on the left
- Menu links on the right (Home, Products, Pricing, Contact)
- On small screens, links should wrap nicely (no overflow)

### 2) Product Cards (Grid)
Create **6 product cards**.
Each card must have:
- Image
- Title
- Short description
- Price
- Button (Add to Cart)

Grid rules:
- Mobile: 1 column
- Tablet (≥ 768px): 2 columns
- Desktop (≥ 1024px): 3 columns

### 3) Responsive Units
Use **rem** for padding and font sizes (example: 1rem, 1.5rem, 2rem).

### 4) Media Queries (Required)
You must add breakpoints at:
- 768px (tablet)
- 1024px (desktop)

### 5) Form Section
Add a “Newsletter” / “Subscribe” section with:
- Email input (required)
- Button

---

## ⭐ Bonus (Optional)
- Add hover effects on cards and buttons
- Add a “Sale” badge on 2 products using `position: absolute`
- Add a sticky header (optional)

---

## ✅ Submission
Submit the complete folder:
- `index.html`
- `style.css`
- `assets/images/*`

Make sure it looks good on mobile and desktop.
